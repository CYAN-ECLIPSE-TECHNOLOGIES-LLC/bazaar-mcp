# FAQ

**Can an agent buy through this server?** No. v0.1.0 is discovery only.
Future purchase hooks are noted, not built: x402 pay-per-call and an Agent
Wallet policy check before any charge.

**What does "not yet certified" mean?** The product has no Test Bench verdict
yet; the server says so explicitly instead of implying quality.

**Why does a listing show a `not_tested` list?** Honesty is the product:
certification states its scope and its gaps.

**Which products are listed?** v0.1.0: the 14-product CETech catalog only.
Third-party listings open in P2, gated by the Test Bench.
