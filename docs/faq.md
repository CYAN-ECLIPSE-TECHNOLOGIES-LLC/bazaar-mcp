# FAQ

**Can an agent buy through this server?** No — this server is the catalog
face (search, compare, certification lookup) and has no purchasing tools.
Priced Bazaar items are purchasable today through the bench-order/intake
path at eclipsebazaar.com (operator-confirmed ordering; no self-serve
buy-now). On the roadmap: x402 pay-per-call and an Agent Wallet policy
check before any charge.

**What does "not yet certified" mean?** The product has no Test Bench verdict
yet; the server says so explicitly instead of implying quality.

**Why does a listing show a `not_tested` list?** Honesty is the product:
certification states its scope and its gaps.

**Which products are listed?** The live Eclipse Bazaar catalog: 156
first-party Cyan Eclipse Technologies MCP servers, connectors, and tools,
each with its Test Bench verdict + scope or an explicit no-verdict
statement. Third-party listings are not yet open; when they open, a
listing passes the Test Bench gate before it can carry a badge.
